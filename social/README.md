# Social-Video-System (PV-Reels)

- `.claude/skills/skript-playbook/SKILL.md`: Regeln für Skripte (Stimme, Aufbau, Recht, Messung).
- `skripte/`: aktuelle Skripte (v2). v1 ist ersetzt.
- `remotion/`: Reel-Vorlage (Untertitel, Zooms, Zahlen-Karte, Endkarte). Render: `npm i && npx remotion render src/index.jsx Reel out/x.mp4`.
- `recherche/`: Berichte Editing und Skript-Conversion (Quellen und Lücken beachten).
Wird nicht auf die Website veröffentlicht (build.sh kopiert nur feste Dateien).
